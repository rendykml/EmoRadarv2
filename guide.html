Panduan Penggunaan EmoRadar

  1. Buka Aplikasi:
    Pastikan aplikasi EmoRadar sudah terinstall di perangkat Anda dan buka aplikasi tersebut.
  2. Izinkan Akses Kamera:
    Saat pertama kali dijalankan, aplikasi akan meminta izin untuk mengakses kamera. Tekan Izinkan agar aplikasi dapat menganalisis ekspresi wajah Anda.
  3. Jika Kamera Tidak Muncul:
    Jika kamera tetap tidak aktif, buka Pengaturan > Aplikasi > EmoRadar > Izin lalu pastikan Kamera sudah diizinkan.
  4. Mulai Kelas:
    Tekan tombol Start Class untuk memulai sesi analisis ekspresi. Kamera akan aktif dan mendeteksi wajah secara real-time.
  5. Lihat Statistik Emosi:
    Statistik emosi Anda akan muncul di bagian Statistik Emosi dan Dominant Expression di layar.
  6. Gunakan Kontrol:
    Anda dapat menyembunyikan/menampilkan informasi usia, landmarks, dan ekspresi dengan tombol Controls.
  7. Akhiri Kelas:
    Tekan tombol End Class untuk mengakhiri sesi.
  8. Cek Log Ekspresi:
    Riwayat ekspresi wajah Anda selama sesi dapat dilihat di bagian Expression Log.
